# Secure Document Storage System

## Project Overview

The **Secure Document Storage System** is a full-stack web application developed using ASP.NET, C#, and Microsoft SQL Server. It provides a centralized platform for storing and managing documents, with authentication and role-based access control to help protect document access.

The project focuses on secure document management, structured database design, and efficient data operations through a web-based interface.

## Project Objectives

- Develop a web application for centralized document storage and management.
- Implement user authentication to control access to the application.
- Apply role-based access control to manage permissions for different users.
- Design a structured SQL Server database for storing document-related information.
- Implement Create, Read, Update, and Delete (CRUD) operations for document management.

## Technologies Used

- **ASP.NET** — Web application development.
- **C#** — Application logic and backend functionality.
- **Microsoft SQL Server** — Database design and data storage.
- **SQL** — Database queries and CRUD operations.

## Key Features

- **User Authentication:** Allows users to access the application through an authentication system.
- **Role-Based Access Control:** Controls application and document access based on assigned user roles.
- **Document Management:** Supports document-related operations through a web interface.
- **Database Management:** Stores and manages document information using SQL Server.
- **CRUD Operations:** Implements creating, retrieving, updating, and deleting records.

## Application Architecture

The application follows a full-stack web architecture:

1. **Frontend:** Web interface for user interaction and document management.
2. **Backend:** ASP.NET and C# handle application logic, authentication, and requests.
3. **Database:** SQL Server stores and manages application and document-related data.

## Getting Started

### Prerequisites

- Visual Studio with the required ASP.NET development workload.
- Microsoft SQL Server.
- SQL Server Management Studio (SSMS), if needed for database management.
- The .NET SDK or .NET Framework version required by the project.

### Setup Instructions

1. Clone or download this repository.
2. Open the `.sln` file in Visual Studio.
3. Configure the SQL Server connection string in the appropriate configuration file.
4. Set up the required database using the project's SQL scripts or migrations.
5. Restore the required NuGet packages.
6. Build and run the application using Visual Studio.

Configure your own local database credentials. Do not commit passwords or sensitive connection strings to GitHub.
